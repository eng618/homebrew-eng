# Homebrew Tap for `eng` CLI
  
Homebrew and Linuxbrew tap for the [`eng`](https://github.com/eng618/eng) CLI tool.

## Installation

```sh
brew tap eng618/eng
brew install --cask eng
```

Or install directly in a single command:

```sh
brew install --cask eng618/eng/eng
```
